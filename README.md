# Story Media Haven

Story Media Haven is a media rating platform where users can share their opinions on their favorite movies and books.
This repository contains the source code and documentation for the design and implementation for this project.

## How to run the program

### 1. Clone the Repository

Open your terminal or command prompt and run:

git clone https://github.com/MasterBuilder2/Story-Media-Haven

cd Story-Media-Haven

### 2. Open the Project in IntelliJ IDEA

1. Launch **IntelliJ IDEA**.
2. Click **Open** on the welcome screen (or go to **File > Open**).
3. Navigate into the cloned repository and select the **`v0.1`** folder, then click **OK**.
4. If prompted to trust the project, click **Trust Project**.

### 3. Configure Source and Test Root Folders

Before running the code or tests, mark the directories so IntelliJ recognizes your source files and unit tests properly:

1. In the **Project** tool window on the left, expand the **`v0.1`** folder.
2. **Set the Sources Root:**
   - Right-click the **`src`** folder.
   - Hover over **Mark Directory as** and select **Sources Root** (the folder icon will turn **blue**).
3. **Set the Test Sources Root:**
   - Right-click the **`test`** folder.
   - Hover over **Mark Directory as** and select **Test Sources Root** (the folder icon will turn **green**).

## Running the Application & Tests

- **Run Main Application:** Locate main.java inside of `src`, right-click the file (or the green play icon next to `public static void main`), and select **Run**.
- **Run Tests:** Right-click the green **`test`** folder (or an individual test file inside it) and select **Run 'All Tests'**.
