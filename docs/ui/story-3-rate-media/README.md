\# Story 3: Rate a Book or Movie



\## User Story



As a book reader or film watcher, I want to rate a book or movie so that I can share my opinion.



\## Acceptance Criteria



Given a user wants to rate a book or movie, when they click the review button, then the system will present a selection input that only allows numeric values between 0 and 5.



Given a user is on a media’s detail page, when they select 4 stars and submit by using the selection input, then the rating is saved.



Given a user is on a media’s detail page, when they select 4 stars and submit by using the selection input, then the book's average rating is updated.
